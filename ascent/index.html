CODEX // DESIGN NOTES

How this mission works

The loop

  1. Read the brief. The mission sets the science target, the data floor, the budget and the risk limit.
  2. Design the stack. Pick a bus, payloads, launch vehicle, ground segment, mission life and test programme.
  3. Watch four budgets. Mass, power, data and cost update live. Red means the design cannot fly.
  4. Run the simulation. The rocket launches in 3D, stages, deploys and reaches orbit.
  5. Read the debrief. Every requirement is checked. Fix, refly, or move to the next study.

What decides the score

  • Science delivered is the largest term. It falls when the downlink cannot return the data you generate.
  • Data returned must clear the mission floor. A camera without a link is a storage problem.
  • Margin and cost efficiency reward a design that is not overbuilt.
  • Risk falls with a proper test programme and rises with thin margins and distance.

No single winning stack. A cheaper design can beat a more capable one if it meets the brief.

Launch, operate, return data.

The four mission segments

  • LaunchVehicle, capacity, ascent.
  • SpaceBus, payload, power, downlink.
  • GroundStations, coverage, data recovery.
  • UserScience returned and used.

Concept Maturity Levels

The campaign follows CML 1–4: cocktail napkin, initial feasibility, trade space, point design. Every debrief asks what a review board would ask next.
